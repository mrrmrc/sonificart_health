# Cartella Video per SonificA.R.T.

## Istruzioni

Per attivare il popup "Vedi come funziona" nella home page, posiziona qui il file video:

**Nome file richiesto:** `presentasonificart.mp4`

### Percorso completo:
```
public/videos/presentasonificart.mp4
```

### Formati supportati:
- **MP4** (raccomandato - massima compatibilità browser)
- WebM (alternativa)

### Specifiche consigliate:
- **Risoluzione:** 1920x1080 (Full HD) o 1280x720 (HD)
- **Codec video:** H.264
- **Codec audio:** AAC
- **Dimensione massima consigliata:** 50MB per caricamenti veloci

### Note:
- Il video verrà riprodotto automaticamente quando l'utente clicca su "VEDI COME FUNZIONA"
- Il video avrà i controlli standard del player (play, pausa, volume, fullscreen)
- Assicurati che il video sia ottimizzato per il web per garantire tempi di caricamento rapidi
